## 👨‍💻 About Me

Hi, I'm **Talha Shahid**, an Artificial Intelligence graduate from **Khawaja Fareed University of Engineering & Information Technology (KFUEIT), Rahim Yar Khan, Pakistan**, with AI/ML internship experience at Ezitech Institute.

My focus is on building practical AI applications using Python, Large Language Models (LLMs), Retrieval-Augmented Generation (RAG), and Agentic AI.

I'm particularly interested in understanding how individual components—LLMs, embeddings, retrieval pipelines, APIs, and agent workflows—come together to create useful AI systems.

I enjoy hands-on learning, experimenting with AI engineering tools, and improving my ability to design, build, debug, and evaluate end-to-end applications.

## 🚀 Projects & Engineering Focus

### 01 · Engineering Manual RAG

**Focus:** Document-based question answering with LLMs.

Exploring a RAG workflow built around an engineering manual, with an emphasis on document ingestion, embeddings, indexing, retrieval, and LLM integration.

**Areas of work:**
- PDF document processing.
- Chunking and embedding generation.
- Vector indexing and retrieval.
- API integration and error handling.
- Building an understandable end-to-end pipeline.

### 02 · Financial Document RAG

**Focus:** Retrieval over financial documents and reports.

Exploring how financial documents, including Bank of Canada publications, can be prepared for retrieval-based AI applications.

**Areas of work:**
- Document collection and extraction.
- Text preparation and chunking.
- Embeddings and semantic search.
- Grounded question answering.
- Retrieval quality and answer evaluation.

### 03 · Agentic RAG

**Focus:** Exploring corrective retrieval workflows and agent orchestration.

Interested in workflows that assess retrieved information, rewrite queries when necessary, retry retrieval, and generate answers grounded in relevant context.

**Concepts I'm exploring:**
- LangGraph nodes and state.
- Conditional edges and workflow routing.
- Retrieval relevance checks.
- Query rewriting and retries.
- Evaluation and debugging.

*These describe my project and learning focus, not claims that every component is complete or deployed.*
